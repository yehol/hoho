# 말랑별 토끼마을

인간의 손이 닿지 않는 작은 행성 "말랑별"에서 아홉 토끼가 함께 사는 마을 공동체 미니 게임.

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요 (로컬에서는 `python3 -m http.server` 후 접속 권장).

## 플레이
- 마을 그림 속 토끼를 눌러 **이야기 나누기**(하루 1번 ♥+1) 또는 **일손 돕기**(미니게임, 일손 1 소모)를 해요.
- 미니게임 보상으로 각 토끼의 재료를 얻고, **요청 게시판**의 부탁을 들어주면 마을 화합도가 올라가요.
- 일손은 하루 6번. **하루 마치기**로 다음 날이 되면 가끔 마을 이벤트가 생겨요.
- 토끼들은 마을 길을 따라 돌아다니며 가족 집에 놀러 가고, 서로 말을 걸어요.
- 아침에 **오늘의 마을 이야기 ▶** 버튼이 뜨면 토끼끼리의 관계 이벤트가 재생돼요. 중간에 반짝이가 선택을 하면 호감도·재료가 달라져요.
- **꾸미기** 탭에서 재료로 장식(11종)을 만들어 마을에 놓을 수 있어요. 좋아하는 토끼 집 근처에 놓으면 보너스. 「놓인 장식 옮기기」로 끌어서 옮기거나 보관함으로 되돌려요.
- 특정 부탁·화합도에 도달하면 **마을 일지**에 이야기가 열려요. 마지막은 「말랑별 대축제」.

| 푸딩 | 캐러멜 | 캐러멜 졸이기 (타이밍) |
| 빵 | 빵 | 빵 굽기 (타이밍) |
| 크림 | 생크림 | 크림 휘핑 (연타) |
| 솜사탕 | 솜사탕 | 그네 밀어주기 (타이밍) |
| 비눗방울 | 비눗방울 | 방울 터뜨리기 |
| 오로라 | 별가루 | 별자리 잇기 |

| 암석 | 반짝돌 | 곁에 가만히 있기 (누르고 싶은 유혹 참기) |

## 가족 관계
- 디저트 삼남매: 초코 · 푸딩 · 빵 (형제)
- 크림: 삼남매의 사촌("케이크 친척"), 솜사탕의 언니. 두 가족을 이어 줌
- 하늘 남매: 오로라 · 구름. 비눗방울은 오로라의 친척… 일지도?
- 암석: 정체불명. 이야기를 진행하면 조금씩 드러남

## 파일

- `assets/village-empty.jpg` 토끼를 지운 마을 배경 (토끼는 스프라이트로 따로 움직임)
- `assets/bunnies/*.png` 캐릭터 시트에서 잘라낸 투명 스프라이트
- `assets/concept/` 원본 컨셉 이미지 (토끼가 그려진 원래 마을 그림 포함)
