# 말랑별 토끼마을

인간의 손이 닿지 않는 작은 행성 "말랑별"에서 아홉 토끼가 함께 사는 마을 공동체 미니 게임.

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요 (로컬에서는 `python3 -m http.server` 후 접속 권장).

## 플레이
- 마을 그림 속 토끼를 눌러 **이야기 나누기**(하루 1번 ♥+1) 또는 **일손 돕기**(미니게임, 일손 1 소모)를 해요.
- 미니게임 보상으로 각 토끼의 재료를 얻고, **요청 게시판**의 부탁을 들어주면 마을 화합도가 올라가요.
- 일손은 하루 6번. **하루 마치기**로 다음 날이 되면 가끔 마을 이벤트가 생겨요.
- 특정 부탁·화합도에 도달하면 **마을 일지**에 이야기가 열려요. 마지막은 「말랑별 대축제」.

## 토끼와 미니게임
| 토끼 | 재료 | 미니게임 |
|---|---|---|
| 초코 | 초콜릿 | 카카오 따기 (익은 것만 탭) |
| 푸딩 | 캐러멜 | 캐러멜 졸이기 (타이밍) |
| 빵 | 빵 | 빵 굽기 (타이밍) |
| 크림 | 생크림 | 크림 휘핑 (연타) |
| 솜사탕 | 솜사탕 | 그네 밀어주기 (타이밍) |
| 비눗방울 | 비눗방울 | 방울 터뜨리기 |
| 오로라 | 별가루 | 별자리 잇기 |
| 구름 | 은빛 물고기 | 강가 낚시 (반응 속도) |
| 암석 | 반짝돌 | 곁에 가만히 있기 (누르고 싶은 유혹 참기) |

## 가족 관계
- 디저트 삼남매: 초코 · 푸딩 · 빵 (형제)
- 크림: 삼남매의 사촌("케이크 친척"), 솜사탕의 언니. 두 가족을 이어 줌
- 하늘 남매: 오로라 · 구름. 비눗방울은 오로라의 친척… 일지도?
- 암석: 정체불명. 이야기를 진행하면 조금씩 드러남
