# 사례별 브랜드 이미지·콘셉트 분석 (17개 사례)

- 작성일: 2026-10-13
- 대상: 처음 조사한 17개 사례 그대로 (라부부 ~ 하츄핑)
- 기준: A단계 근거조사에서 확인한 "예쁨 다음에 갈리는 세 가지", 즉 **익숙함 · 성격과 행동 · 감정 가치(자기투영)**를 사례마다 같은 틀로 본다.
- 표기: **공식**은 회사·작가 발표, **2차**는 기사·리뷰·팬 자료, **관찰**은 공식 이미지를 보고 적은 것, **해석**은 이 문서의 분석이다.
- 한계: 공식 캐릭터 설정 페이지 상당수에 직접 접속하지 못해 기사·인터뷰 인용으로 확인했다. 프릳츠 물개는 설정 자료를 찾지 못해 이미지 관찰로만 적었다.

---

## 한눈에 보는 결론

1. **오래 사랑받는 캐릭터에는 "예쁨 + 반전"이 있다.** 귀여운 겉모습에 결핍이나 예상 밖의 감정이 붙어 있다. 갈기 없는 사자(라이언), 착한데 사고뭉치(라부부), 죽은 눈의 미키(KAWS), 귀여운 얼굴에 거친 입담(김햄찌), 하찮지만 중요한 존재(조구만). (해석)
2. **감정은 크게 다섯 갈래로 나뉜다.** 장난·반항 / "내 얘기" 공감 / 위로·치유 / 유머·놀람 / 의미·자부심. 같은 갈래 안에서도 성격 설정이 분명한 쪽이 매출·인지도 근거가 더 많다. (해석)
3. **비주얼은 "기호 하나 + 표정 절제"가 공통이다.** X형 눈, 이빨, 없는 입처럼 기억되는 기호는 하나뿐이고, 표정은 단순해서 보는 사람이 감정을 얹을 수 있다. 산리오는 헬로키티에 입이 없는 이유를 "보는 사람이 자기 감정을 투영할 수 있게"라고 설명했다. (공식 + 해석)
4. **묘브제에 비어 있는 것은 "성격과 반전"이다.** 물질의 인상(폭신함, 묵직함)과 감정 질문은 있지만, 각 토끼가 어떤 성격이고 어디가 모자란지가 없다.

**읽는 법**
- A단계의 팝마트 데이터에서도 감정 주제가 분명한 캐릭터(CRYBABY, HIRONO 등)가 빨리 컸다. 이번 17개 사례에서도 매출·인지도 근거가 큰 쪽(라부부, 산리오, 카카오, 김햄찌)은 성격 설정이 분명하다.
- 단, 감정 갈래 자체에 우열은 없다. 위로형(토토로)과 반항형(라부부) 모두 크게 성공했다. 갈리는 것은 **갈래 안에서 성격이 얼마나 분명한가**다.

## 3. 공통 법칙 세 가지 (해석)

**① 예쁨 + 반전(결핍)**
| 사례 | 예쁨 | 반전·결핍 |
|---|---|---|
| 라부부 | 털 봉제의 귀여움 | 이빨, 사고뭉치 |
| 라이언 | 둥근 얼굴 | 갈기 없는 수사자 |
| 쿠로미 | 귀여운 토끼 모자 | 펑크, 터프함 |
| KAWS | 미키를 닮은 몸 | X형 눈, 해골 |
| 김햄찌 | 햄스터 | 거친 입담, 번아웃 |
| 조구만 | 작은 공룡 | 하찮음, 어두운 유머 |
| 스티키몬스터랩 | 원색의 단순한 몸 | 팔이 없음, 현실의 어두움 |

**② 기호는 하나, 표정은 절제**
기억되는 기호는 하나다(X형 눈, 이빨, 없는 입, 갈매기 무늬). 표정은 단순하거나 무표정이라 보는 사람이 감정을 얹는다. 헬로키티의 입이 없는 이유에 대한 산리오 설명이 이 원리를 직접 말한다.

**③ 이름이나 문장이 감정을 바로 전달**
하츄핑(사랑), 최고심(긍정 문장), 조구만(작은 존재) 같은 이름과 문장은 설명 없이 감정을 알려 준다. 긴 세계관보다 빠르다.

## 4. 묘브제 점검 (가설, 검증 전)

| 기준 | 묘브제 현재 | 비어 있는 것 |
|---|---|---|
| 예쁨 | 공통 몸 비례·얼굴, 저채도 자연색 | 실물 완성도 확인 필요 |
| 성격·행동 | 물질의 인상만 있음 (폭신하고 따뜻함, 묵직하고 단단함 등) | 각 토끼가 무엇을 하고 어떤 성격인지 |
| 반전·결핍 | 없음 | 겉모습과 다른 속마음, 모자란 점 |
| 감정 가치 | 물질별 질문이 감정에 닿아 있음 ("조금 더 단단해지고 싶은 순간은 언제야?") | 질문과 성격이 연결되어야 함 |
| 기호 | 공통 실루엣 계획 | 한눈에 기억될 기호 하나 |
| 표정 | 미정 | 투영형(절제)으로 갈지, 표현형으로 갈지 결정 |
| 이름·문장 | "당신은 어떤 토끼인가요?" | 토끼 이름이 감정이나 성격을 바로 전달하는지 |

**성격·반전을 붙이는 방식의 예 (방향을 보여주기 위한 예시일 뿐, 제안 아님)**
- 암석토끼: 겉은 묵직하고 단단함 → 속은 쉽게 금이 갈까 걱정함
- 구름토끼: 겉은 가볍고 부드러움 → 어디에도 오래 머물지 못함

이런 설정이 실제로 선호를 만드는지는 다음 단계(묘브제 성격·감정 설정 초안, 선호 조사)에서 확인한다.
